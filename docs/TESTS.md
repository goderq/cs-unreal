# Приёмочные тесты

Тесты нумеруются сквозно по ТЗ §24. Этап считается закрытым, когда все его
тесты проходят.

## Этап 1 — базовый multiplayer

Запуск: PIE, `Number of Players = 2`, `Net Mode = Play Standalone`,
`Run Under One Process` **выключено**.

| # | Тест | Ожидаемый результат |
|---|---|---|
| 1.1 | Проект собирается | `Development Editor` компилируется без ошибок; в логе сборки `[CSFusion] Photon Fusion 3 SDK found -> CS_WITH_FUSION=1` |
| 1.2 | Подключение к Photon | В логе `Session state: None -> Connecting -> Connected -> JoiningRoom -> InRoom` |
| 1.3 | Два игрока в комнате | В обоих окнах `CSNetInfo` показывает `players=2` и одинаковое имя комнаты |
| 1.4 | Ровно один авторитет | В одном окне `authority=YES`, в другом `authority=no` |
| 1.5 | Спавн | Оба персонажа появились на разных `PlayerStart` |
| 1.6 | Репликация движения | Игрок A двигается — игрок B видит это в своём окне, и наоборот |
| 1.7 | First person | Свой персонаж — только руки и тень; чужой — полная модель |
| 1.8 | Движение | WASD, мышь, `Space` прыжок, `LeftShift` спринт (скорость 420 → 620), `LeftCtrl` присед (капсула 88 → 60, скорость 220) |
| 1.9 | Спринт не назад | Спринт не ускоряет движение назад и вбок (порог dot 0.5) |
| 1.10 | Фазы матча | Через 5 с после входа фаза меняется на `Warmup`, затем `InProgress`; смена видна в обоих окнах |
| 1.11 | Глобальный RPC | Сообщения «Warmup started» / «Round started» появляются в логе **обоих** клиентов, но отправляет их только авторитет |
| 1.12 | Master migration | Закрыть окно-авторитет → во втором окне в логе `local player is NOW the authority`, фазы матча продолжают идти |
| 1.13 | Выход | `LeaveMatch()` возвращает состояние в `Connected`, персонаж удаляется у остальных (PlayerAttached) |
| 1.14 | Offline-путь | Запустить PIE с 1 игроком и не входить в комнату: `CSNetInfo` показывает `backend=Offline`, `authority=YES`, фазы матча идут, announcement'ы попадают в лог через прямой вызов `_Receive` |
| 1.15 | SDK обязателен | Временно переименовать `Plugins/PhotonFusion` → сборка падает с понятным `BuildException` и ссылкой на `docs/PHOTON_SETUP.md`, а не молча собирается в сломанном виде |

## Этап 2 — бой (план)

| # | Тест |
|---|---|
