# Графика (v2.0, фаза 5)

## Что в проекте

- **Shader Model 6, DX12.** SM5 больше не собирается (AUDIT B14, К6).
- **Аппаратная трассировка лучей** (`r.RayTracing=True`, включается во время
  игры через `r.RayTracing.EnableOnDemand`):
  - по умолчанию выключена;
  - включается в настройках, если GPU и драйвер её поддерживают
    (`IsRayTracingAllowed()`);
  - тогда Lumen трассирует аппаратно (`r.Lumen.HardwareRayTracing`);
  - без неё — программный Lumen по distance fields.
- **Distance fields** (`r.GenerateMeshDistanceFields=True`):
  - нужны программному Lumen;
  - до фазы 5 не строились вообще (значение движка по умолчанию — выключено),
    поэтому Lumen GI и отражения не работали с v1.1 — тот самый «плоский свет»
    из AUDIT §7;
  - нашёл графический самотест.
- **Сглаживание и апскейл:** NVIDIA DLSS → TSR → TAA.
  - TSR — по умолчанию в проекте (раньше был TAA).
  - DLSS — если установлен плагин и GPU его поддерживает.
- **Тени:** Virtual Shadow Maps. Контактные тени у солнца (0,03) и у ламп в
  помещениях (0,02), их ставит `Scripts/build_maps.py`.

## Настройки игрока

Экран **Settings → Video**. Хранятся в `GameUserSettings.ini` через
`UCSGameUserSettings`.

| Настройка | Значения |
|---|---|
| Пресет | Low, Medium, High, Epic, Cinematic, Custom |
| Группы (ручная настройка) | дальность прорисовки, сглаживание, тени, глобальное освещение, отражения, пост-обработка, текстуры, эффекты, шейдинг — каждая Low…Cinematic; изменение любой делает пресет Custom |
| Сглаживание / апскейлер | NVIDIA DLSS (только где работает), TSR, TAA |
| Разрешение рендера | Native (100 %, с DLSS — DLAA), Quality 67 %, Balanced 58 %, Performance 50 %, Ultra Performance 33 % |
| Аппаратная трассировка | Off / On; на неподдерживающем GPU — «Not supported on this PC» |
| Разрешение, режим окна, лимит FPS, VSync, счётчик FPS | как раньше |
| **AUTO-DETECT** | бенчмарк движка, затем DLSS Quality (если есть) или TSR; трассировка — только при 8 ГБ видеопамяти и больше |

При первом запуске на ПК автоподбор выполняется сам. Тесты запускаются с
`-noautodetect`, чтобы их цифры были сравнимы.

Под строками — видеокарта, объём видеопамяти и состояние DLSS (почему он
недоступен, если недоступен).

## DLSS в игре (К5)

- **В сборке игры DLSS есть всегда**, как во всех играх: лицензия NVIDIA RTX SDK
  разрешает поставлять плагин в составе игры.
  - `Scripts/package_release.ps1` ставит плагин, если его нет в `Plugins/`, и
    останавливает упаковку, если поставить не из чего.
  - После упаковки проверяет, что в билде лежит `nvngx_dlss.dll` (его кладёт
    сам плагин, RuntimeDependencies).
  - Собрать без DLSS можно только явно: `-NoDLSS`.
  - Проверено 26.09: Development-сборка за 4 минуты, в ней
    `CSFusion\Plugins\DLSS\Binaries\ThirdParty\Win64
vngx_dlss.dll`;
    `run_tests.ps1 -Packaged -Only graphics` — 12/12, DLSS включён в самой
    собранной игре.
- **Не в публичном git** — только файлы самого плагина; остальное ниже про
  это.


- Плагин NVIDIA нельзя класть в публичный git: `Plugins/DLSS*/` и
  `Plugins/Streamline*/` в `.gitignore`.
- Код его не подключает (`Build.cs` без зависимостей). `Graphics/CSGraphics.cpp`
  находит Blueprint-библиотеку плагина (`/Script/DLSSBlueprint.DLSSLibrary`) и
  вызывает её функции через рефлексию:
  - `IsDLSSSupported`, `QueryDLSSSupport`, `EnableDLSS`, `IsDLSSModeSupported`,
    `IsDLSSEnabled`;
  - процент рендера задаёт движок (`r.ScreenPercentage` через resolution scale);
  - спрашивать плагин можно только после `PostEngineInit`, поэтому настройки
    применяются ещё раз кадром позже.
- **Без плагина** проект собирается и работает на TSR/TAA, пункта DLSS в меню
  нет. Проверено: сборка и графический тест до установки плагина — 10/10.
- **Установка у себя:**
  1. скачать «DLSS for Unreal Engine 5.8» с
     https://developer.nvidia.com/rtx/dlss/get-started;
  2. `powershell -ExecutionPolicy Bypass -File Scripts\install_dlss.ps1`
     (берёт архив из `SourceArt\_download`);
  3. пересобрать проект.

  Ставятся только `DLSS` и `StreamlineNGXCommon`. Генерация кадров (DLSS-G)
  нужна RTX 40 и новее, Reflex — отдельный плагин; не ставились.
- Версия: 8.8.0 (DLSS 4.5, NGX 310.9.1) под UE 5.8.0; на странице NVIDIA на
  26.09.2026 — 8.7.2, наша не старее.

## Замеры

`-cstestgraphics` (набор `graphics`), Depot, RTX 3050 Laptop (4 ГБ), драйвер
владельца, 26.09.2026. Кадры считаются 4 с после 4 с на прогрев. Раннер
запускает тест в окне 960×540; отдельно тот же тест прогнан в 1920×1080.

| Случай | 960×540 | 1920×1080 |
|---|---|---|
| Low | 233 FPS | 110 FPS |
| Medium | 145 | 72 |
| High | 123 | 54 |
| Epic | 83 | 23 |
| Epic + TAA | 94 | 40 |
| Epic + TSR Performance (50 %) | 108 | 67 |
| Epic + DLSS Quality (67 %) | 98 | 60 |
| Epic + DLSS Performance (50 %) | 101 | 58 |
| Epic + аппаратная трассировка | 93 | 26 |
| Cinematic | 12 | 3 |

- Цифры с работающим Lumen. До исправления distance fields Epic давал 137 FPS
  (960×540), потому что GI не считался вовсе.
- Cinematic переполняет 4 ГБ видеопамяти. Поэтому:
  - в тесте он идёт последним — случай после него однажды мерил последствия,
    TAA 18 FPS;
  - автоподбор ниже 6 ГБ останавливается на Epic;
  - пресет по умолчанию — High (у движка — Epic).
- Для этого ноутбука разумно: High с DLSS Quality или Epic с DLSS/TSR на
  50–67 % — около 60 FPS в 1080p.
- Трассировка на 4 ГБ почти не дороже программного Lumen (26 против 23 FPS),
  но и не быстрее: включается по желанию.

Задержка отдельно от FPS — набор `perf`:
- строка `PERF TEST RESULT: latency`: оценка «игровой поток + рендер + GPU
  одного кадра»;
- замер движка «ввод → vblank» (`GInputLatencyTime`) — где драйвер сообщает
  время показа кадра; на RTX 3050 он приходит и в окне. Если не приходит, так
  и пишется.
- 26.09, Depot, 8 ботов, 960×540, Epic: 83 FPS (p95 13,0 мс); задержка —
  оценка 28,3 мс, движок «ввод → vblank» 37,7 мс.

## Что не сделано

- Генерация кадров (DLSS-G) и Reflex: первое не работает на RTX 3050, второе —
  отдельный плагин и отдельное решение.
- Трассированные тени (`r.RayTracing.Shadows`): тени остаются на VSM. На 4 ГБ
  видеопамяти трассировку Lumen включать и так имеет смысл только по желанию.
- Материалы (вариации, декали, trim sheets) — в работу по визуалу карт,
  отдельно.
